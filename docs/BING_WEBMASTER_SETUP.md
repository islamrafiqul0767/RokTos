# Bing Webmaster Tools Setup

1. **Access Webmaster Tools**:
   - Go to https://www.bing.com/webmasters.
   - Import verification directly from Google Search Console, or add the URL prefix.
2. **Submit Sitemap**:
   - Enter `https://<YOUR_DOMAIN>/sitemap.xml`.
3. **Crawl Control**:
   - Verify that robots.txt is parsed correctly and that private routes (`/donors`, `/admin`, `/dashboard`) remain disbarred from crawling.
