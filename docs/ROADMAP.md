# Product Roadmap

## Phase 1 (Completed — Current Release)
- [x] Full-Stack Firebase integration with Google Auth and Cloud Firestore.
- [x] Zero-Trust ABAC Security Rules with split-collection privacy projection.
- [x] Public donor discovery directory with Bangladesh divisions, districts, and blood group filters.
- [x] Consent-based seeker-to-donor contact request flow.
- [x] Structured blood donation request submission with urgency classification.
- [x] Staff moderation console with verification reviews, abuse report queue, and audit logs.
- [x] Bilingual Bengali-first and English-ready interface.
- [x] Technical SEO suite: meta tags, canonicals, robots.txt, sitemap.xml, Schema.org JSON-LD.
- [x] Automated unit test suite with Node 22 test runner.

## Phase 2 (Planned Future Enhancements)
- [ ] Push notifications (PWA / Firebase Cloud Messaging) for accepted contact requests.
- [ ] Direct blood-bank inventory integrations with authorized public hospital blood centres.
- [ ] Automated scheduled Cloud Functions to archive expired blood requests after 30 days.
- [ ] Highly secured, ephemeral reviewer upload pipeline for identity documents if legal and data-retention protocols are established by the owner.
