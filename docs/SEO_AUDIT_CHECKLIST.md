# SEO Audit Checklist

- [x] Unique, descriptive `<title>` and `<meta name="description">` on all public routes.
- [x] Single `<h1>` per page with logical `<h2>` and `<h3>` visual hierarchy.
- [x] OpenGraph meta tags (`og:title`, `og:description`, `og:type`) in `index.html`.
- [x] Canonical tags pointing to authoritative URLs without development parameter pollution.
- [x] Validated `public/robots.txt` disallowing private and admin routes.
- [x] Validated `public/sitemap.xml` listing canonical indexable pages.
- [x] Noindex applied to dynamic user search results (`/donors`), admin console, and account dashboards.
- [x] Validated Schema.org JSON-LD without fabricated reviews or ratings.
- [x] Responsive layout with viewport meta tag and accessible touch targets.
